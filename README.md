# ☁️ Cloud Computing & AWS

Repositorio dedicado al aprendizaje, documentación y desarrollo de competencias avanzadas en Computación en la Nube (Cloud Computing), con un enfoque principal en Amazon Web Services (AWS) y bases en Microsoft Azure[cite: 1].

## 🎯 Objetivo

Desarrollar habilidades técnicas sólidas y competencias integrales para diseñar, implementar, administrar, asegurar y automatizar infraestructuras y aplicaciones escalables en entornos multi-cloud[cite: 4, 15].

---

## 🚀 Competencias Adquiridas

*   **Competencia Técnica en AWS y Azure:** Dominio integral de los servicios clave de AWS (desde computación y redes hasta almacenamiento y seguridad), junto con conocimientos introductorios y fundamentales de Microsoft Azure[cite: 1, 15].
*   **Diseño y Administración de Infraestructura en la Nube:** Creación, configuración y gestión eficiente de redes virtuales (VPC), sistemas operativos Linux mediante SSH, servidores web, sistemas de enrutamiento (Route 53) y entornos virtualizados con Amazon EC2[cite: 4, 5, 6, 7].
*   **Desarrollo de Aplicaciones y Arquitectura Serverless:** Capacidad para diseñar y desplegar software nativo de la nube, con énfasis en arquitecturas sin servidor utilizando *AWS Lambda*, integrando SDKs y herramientas de desarrollo[cite: 11, 15].
*   **Automatización e Infraestructura como Código (IaC):** Automatización avanzada de tareas operativas y despliegue de infraestructura mediante *Terraform*, *AWS CloudFormation*, *AWS CDK* y scripts automatizados en Bash[cite: 5, 9, 15].
*   **Gestión de Bases de Datos y Big Data:** Implementación, configuración y administración tanto de bases de datos relacionales SQL (*Amazon RDS*) como NoSQL (*DynamoDB*, *DocumentDB*), además de la integración de soluciones analíticas y de Big Data como *Amazon Redshift* y *Elastic MapReduce*[cite: 8, 12, 15].
*   **Desacoplamiento y Arquitectura de Microservicios:** Diseño de sistemas escalables y orientados a eventos mediante el desacoplamiento de cargas de trabajo con *API Gateway*, colas de mensajes (*SQS*) y servicios de mensajería (*SNS*)[cite: 12, 15].
*   **Contenedores y Orquestación:** Empaquetado y gestión de aplicaciones mediante *Docker*, y su respectiva orquestación a escala en la nube utilizando *Amazon ECS*, *EKS* y *AWS Fargate*[cite: 12].
*   **Implementación de Pipelines CI/CD:** Automatización de procesos de integración y entrega continua de software empleando *AWS CodePipeline*, *CodeBuild*, *CodeDeploy* y flujos de trabajo en *GitHub Actions*[cite: 13].
*   **Seguridad y Control de Acceso:** Aplicación de las mejores prácticas de seguridad en entornos cloud mediante la gestión estricta de identidades (*IAM*), políticas de cifrado (*KMS*, *Secrets Manager*) y el uso de servicios avanzados de protección (*AWS WAF, Shield, Inspector y GuardDuty*)[cite: 9, 15].
*   **Monitoreo, Analítica y Observabilidad:** Configuración de sistemas de monitorización y gestión de registros a través de *Amazon CloudWatch*, el stack ELK (*Elasticsearch, Logstash, Kibana*), *New Relic* y *Datadog*[cite: 9, 13].

## 🛠️ Tecnologías y Herramientas

*   **Cloud Computing:** Amazon Web Services (AWS), Microsoft Azure[cite: 1].
*   **Sistemas y Automatización:** Linux, Bash, SSH, Terraform, AWS CloudFormation, AWS CDK[cite: 5, 9].
*   **Infraestructura y Redes:** EC2, S3, EBS, EFS, VPC, Route 53, CloudFront, Elastic Load Balancing (ELB), VPN, Direct Connect[cite: 6, 7, 8, 9].
*   **Bases de Datos y Big Data:** Amazon RDS, DynamoDB, DocumentDB, Amazon Redshift, Elastic MapReduce, QuickSight[cite: 8, 12].
*   **Desarrollo, Contenedores y DevOps:** Python, Docker, Kubernetes, Amazon ECS, EKS, Fargate, AWS Lambda, API Gateway, SQS, SNS, AWS CodePipeline, CodeBuild, CodeDeploy, CI/CD, GitHub Actions[cite: 11, 12, 13].
*   **Seguridad y Monitoreo:** IAM, KMS, Secrets Manager, WAF, Shield, Inspector, GuardDuty, CloudWatch, ELK Stack, New Relic, Datadog[cite: 9, 13].
