Acerca de este espacio

Este repositorio está orientado al aprendizaje de Cloud Computing y los servicios de Amazon Web Services (AWS). Su propósito es documentar conocimientos, comprender arquitecturas tecnológicas y explorar herramientas utilizadas en entornos de computación en la nube.

Mi enfoque profesional

Como estudiante de Ingeniería de Sistemas, busco fortalecer mis competencias en infraestructura cloud, administración de servicios, automatización, escalabilidad y arquitectura de soluciones tecnológicas.

Amazon Web Services

AWS ofrece servicios de computación en la nube que permiten construir, implementar y administrar soluciones tecnológicas.

🖥️

Amazon EC2

Servicio de servidores virtuales para ejecutar aplicaciones y cargas de trabajo en la nube.

🪣

Amazon S3

Servicio de almacenamiento de objetos para guardar y administrar información.

🗄️

Amazon RDS

Servicio administrado para trabajar con bases de datos relacionales.

🌐

Amazon VPC

Permite crear redes virtuales aisladas y configurar recursos de infraestructura.

⚡

AWS Lambda

Permite ejecutar código sin administrar directamente servidores.

🔗

API Gateway

Servicio para crear, publicar y administrar interfaces de programación de aplicaciones.
